# Singular Value Decomposition 
Singular Value Decomposition (SVD) is one of the most important concepts in linear algebra, especially in the context of machine learning, data analysis, and dimensionality reduction. SVD decomposes any matrix into three 
other matrices as: <br>

<div align="center" font-size="200%">
  
$$
\huge{A = U \Sigma V^T}
$$

</div>
